# Changelog

## Unreleased

- Reports end with a plain "Generated by Refit" line; the line about paid upgrade services is gone.
- `refit fix` no longer follows a symlinked PHP file and rewrites a target outside the project.
- Scan reports keep the same file names and counts when the temporary directory path is a symlink.
- Bundled Composer libraries are found without `GLOB_BRACE`, which musl PHP (Alpine) does not define.
- Dynamic properties are no longer declared on classes that use `__get`, `__isset` or `__unset` (including through a parent or trait). Those classes get `#[\AllowDynamicProperties]` instead, so the magic methods keep running. Declaring a property also changes `property_exists()`, `get_object_vars()` and `json_encode()`.

## 0.1.0 (unreleased)

First release.

- `refit scan`: compile check, PHPCompatibility, a DateTime::modify() check for PHP 8.3,
  dynamic property detection, and a dry run of the automatic fixes. Reports in the console,
  HTML, Markdown and JSON.
- `refit fix`: applies 54 compatibility-only fixes in place, keeps the project's
  indentation, restores any file that stops compiling, and leaves bundled libraries alone.
- Understands WordPress plugin and theme headers, readme.txt and composer.json to find the
  oldest PHP version the code must keep supporting.
